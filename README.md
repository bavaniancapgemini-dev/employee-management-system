## Employee Management System

A simple Python-based Employee Management System that allows users to manage employee records using SQLite database integration. This project is designed for gebinners to practice Python, database handling, modular programming, and GitHub project management.

## Features

- Add Employee
- View Employee
- Search Employee
- Delete Employee
- Update Employee Salary
- Highest Salary Report
- Average Salary Report
- Modular File Structure
- Beginner-Friendly Project

## Project Structure

employee-management-system/
│── main.py
│── database.py
│── reports.py
│── utils.py
│── employees.db

## Technologies Used

- Python

## How to Run the Project

# Step 1 — Clone Repository
git clone https://github.com/bavani/employee-management-system.git
# Step 2 — Open Folder
Open the project folder in VS Code
# Step 3 — Run Application
python main.py
